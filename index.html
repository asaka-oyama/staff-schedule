🔧 Firebase設定手順

  1. Googleアカウントで Firebase Console を開く
  2. 「Realtime Database」を作成 → テストモードで開始
  3. プロジェクト設定 → ウェブアプリを追加 → firebaseConfig をコピー
  4. このHTMLの FIREBASE_CONFIG 部分を書き換えて保存 → OneDriveで共有
const FIREBASE_CONFIG = {
  apiKey: "AIzaSy...",
  databaseURL: "https://your-project-default-rtdb.asia-southeast1.firebasedatabase.app",
  ...
};
